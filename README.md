# 🎓 University Internship Career Management System

## 📖 Overview

The **University Internship Career Management System** is a MERN Stack web application designed to simplify the internship recruitment process by connecting students, companies, and university administrators on a single platform.

The system allows students to create professional profiles, receive internship recommendations based on their qualifications, apply for internship opportunities, and track their application progress. Companies can publish internship opportunities, review applications, schedule interviews, and update recruitment statuses through an efficient management interface.

### 👨‍🎓 Student

* Register and Login
* Manage Student Profile
* Upload Resume/CV
* View Recommended Internship Opportunities
* Search Available Internships
* Apply for Internships
* Track Application Status
* View Interview Details
* Confirm Interview Attendance
* Request Interview Rescheduling
* Receive Notifications

### 🏢 Company

* Register Company Account
* Manage Company Profile
* Post Internship Opportunities
* Edit/Delete Internship Posts
* View Student Applications
* Shortlist Candidates
* Schedule Interviews
* Update Application Status
* Hire or Reject Applicants

### 👨‍💼 Administrator

* Manage Students
* Manage Companies
* Manage Internship Listings
* Monitor System Activities
* Generate Reports

# 🔄 System Workflow

1. Student registers an account.
2. Student completes their profile.
3. Companies publish internship opportunities.
4. The system recommends matching internships.
5. Student applies for internships.
6. Company reviews applications.
7. Company shortlists candidates.
8. Company schedules interviews.
9. Student views interview details and confirms attendance.
10. Company updates the final application status.
11. Student views the final hiring result.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/university-internship-career-management-system.git
```

## Navigate to the Project

```bash
cd university-internship-career-management-system
```

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

## Frontend Setup

```bash
cd frontend
npm install
npm start
```

> If your project uses Vite, run:

```bash
npm run dev
```
